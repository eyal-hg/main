# HK Dashboard — פרוטוטייפ ממשק

פרוטוטייפ סטטי (ללא build, נפתח ישירות מ־`file://` או מכל שרת סטטי) של מסכי הדשבורד:
מנהל תזרים (HK) · יועץ · לקוח (חברה אחת / רב־חברות).

## מבנה הפרויקט

```
index.html          שלד ה־HTML בלבד — top bar, rail, views, מודלים
css/
  base.css          טוקנים (צבעים/צל/רוחב rail), reset, top bar, shell+rail, כותרת מסך, טאבים
  dashboard.css     עורך מדדים, לוח ווידג'טים, פיקר, צ'אט AI
  portfolio.css     תור התפעול (בית מנהל תזרים), מוקד התראות + מפת בריאות
  ops.css           מצב תפעול: באנר, שורות משימות, זרימת סיום (Bizibox)
  chat.css          FAB, מגירת וואטסאפ, אינבוקס הודעות
  meetings.css      מסך פגישות + מודל סיכום פגישה
js/
  data.js           נתוני דמו: CLIENTS (בפרודקשן — שכבת API)
  core.js           rail הלקוחות, מחליף החברות
  board.js          CATALOG/BOARDS של ווידג'טים, רנדור הלוח, גרירה, פיקר
  screens.js        ניתוב scope/תפקיד (setScope/setRole דרך screens), מגירת צ'אט, toast,
                    טאבים, עורך מדדים + חוקי התראה, צ'אט AI, דוחות
  ops.js            מצב תפעול: טיימר מצטבר, כניסה/יציאה (History API #ops),
                    זרימת סיום — בדיקות Bizibox, ממצאים, שליחת תזרים ללקוח
  queue.js          תור התפעול חוצה־חברות, לוגו מוצרים (HK Money/Meeting/Money+)
  alerts.js         מנוע התראות לפי מדד (METRICS[].alert), מוקד התראות, מפת בריאות
  topbar.js         תפריט סטטוס לקוח, פילטר מוצרים, אינבוקס, דוח תזרים מאוחד
  meetings.js       רשימת פגישות + סיכום
  main.js           bootstrap
widgets/            ווידג'טים עצמאיים (iframe) — כל קובץ HTML שלם
logo.*.svg          לוגו חזות קריספין
```

## עקרונות

- **סקריפטים קלאסיים, scope גלובלי משותף** — אין מודולים/בנדלר בכוונה. סדר הטעינה
  ב־`index.html` הוא סדר ההרצה; `main.js` חייב להיות אחרון. אירועי UI מחווטים
  ב־`onclick` אינליין, לכן הפונקציות גלובליות.
- **סדר קבצי ה־CSS = סדר הקסקדה** — אל תשנו את סדר ה־`<link>`.
- **RTL** — הקבצים משתמשים ב־logical properties (`inset-inline-start` וכו').
  שימו לב: `inset-inline-start` = ימין ב־RTL.
- **ווידג'טים ב־iframe** — כל ווידג'ט נטען עם `#embed`; הוא מוסיף לעצמו
  `html.embed`, מסתיר כרום פנימי, ומדווח גובה ב־`postMessage({hkEmbed:1,src,h})`.
  המאזין ב־`board.js` מעדכן את גובה ה־iframe ואת ה־row-span של המזונרי.
- **מצב תפעול ↔ URL** — כניסה דוחפת `#ops` (History API); Back בדפדפן סוגר את
  המצב ושומר את הזמן. בפרודקשן זה יוחלף ב־router אמיתי + deep-linking.
- **התראות לפי מדד** — כל מדד ב־`METRICS` (screens.js) נושא `alert:{on,cmp,th}`;
  `alerts.js` רק מריץ את החוקים על החברות. מדרגי: בפרודקשן הספירות וה־worst-N
  מחושבים בשרת.

## התאמה לפי תפקיד (persona)

| תפקיד | בית "כל החברות" | הערות |
|---|---|---|
| מנהל תזרים (HK) | תור תפעול ↔ מוקד התראות (טוגל) | רואה מוצרים, תפעול, Bizibox |
| יועץ | מוקד התראות + מפת בריאות + פגישות | ללא מוצרים וללא כלי תפעול |
| לקוח רב־חברות | מבט מאוחד (ווידג'טים מצרפיים) | ללא rail וכלי משרד |
| לקוח חברה אחת | דשבורד חברה בלבד | ללא מחליף חברות |

## הערות הטמעה

- `data.js` הוא ה־contract של הנתונים — כל שדה שם נצרך איפשהו ב־UI.
- הקבצים ב־`js/` ממופים אחד־לאחד למסכים/דומיינים — מועמדים טבעיים לקומפוננטות.
- אין תלות חיצונית מלבד גופן Rubik מ־Google Fonts.
