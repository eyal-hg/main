# תיעוד אירועים על ליד

## מה זה?
יומן כרונולוגי לכל ליד — מאיפה הגיע, מי שינה לו סטטוס, מתי תואמה פגישה, ומה הנציגים כתבו.

## גישה
אייקון **📋** בשורת הליד (עם מונה רשומות). קליק → היומן נפתח.

## מה נרשם אוטומטית (כולל שם נציג + תאריך/שעה)
1. **יצירת ליד** — מאיפה הגיע
2. **שינוי סטטוס** — חדש ← נוצר קשר
3. **קביעת פגישה**
4. **הזזת פגישה**
5. **ביטול פגישה**

## מה נרשם ידנית
שדה טקסט חופשי בראש היומן ("הוסף הערה").

## הבחנה ויזואלית
- אוטומטי → רקע נטרלי + תג "אוטומטי"
- ידני → כרטיס צהוב בולט + תג "הערה ידנית"

## הרשאות
לראות + להוסיף — כל נציג. למחוק — רק מנהל.
