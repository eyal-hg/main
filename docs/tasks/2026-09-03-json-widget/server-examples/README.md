# דוגמאות לשרת — מה הוא צריך להחזיר ב-GET /api/widgets/{company}/{widget}

חמישה קבצים, כל אחד = תשובה מלאה של השרת לטבלה אחת: `view` (איך להציג) + `types` + `rows` + `received_at`.
ליד כל JSON: **קובץ HTML עצמאי** (הספרייה + הנתונים בפנים — פותחים בדפדפן ורואים את הווידג׳ט) ותמונה של התוצאה (חצי מסך). החוזה המלא: `docs/WIDGET_JSON_CONTRACT.md`.

| קובץ | מה מודגם ב-view |
|---|---|
| `gviya__customer_balances.json` | מיון לפי יתרה, פס כחול ליתרה, "מתוכה באיחור" אדום ופס אדום כשגדול מאפס, סכום מסמכים |
| `gviya__payment_terms.json` | הסתרת 3 עמודות לחצי מסך, סדר עמודות, יחידה "ימים", פער ירוק/ענבר/אדום לפי סף, ממוצע בסה״כ |
| `gviya__unbilled.json` | גיל בימים עם סף 30/90 ופס ענבר, צ׳יפ "סוג" עם צבעים משלו, הסתרת עמודות |
| `sales__sales.json` | הסתרת מע"מ ולפני מע"מ, מיון לפי תאריך, יתרה פתוחה בענבר, סטטוס לפי המפה הקבועה |
| `tazrim__future_cashflow.json` | מיון עולה לפי תאריך תשלום, הסתרת עמודה שכל ערכיה זהים, פס ליתרה, סכום |
