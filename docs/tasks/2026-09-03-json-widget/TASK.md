# משימה: ווידג׳ט "טבלה מ-JSON" בדשבורד בעל העסק — הנחיה ל-AI של המתכנת

> **איך לקרוא את הקובץ הזה.** אתה ה-AI שמוסיף למערכת הווידג׳טים הקיימת של HK ווידג׳ט אחד חדש
> שמציג טבלה מכל JSON ששרת הווידג׳טים שולח. הקובץ הזה הוא המקור היחיד למשימה. הוא מכיל:
> (א) מה יש כבר מוכן ומה אתה בונה, (ב) מאיפה מגיעים הנתונים, (ג) איך מפרסרים ומרנדרים,
> (ד) קריטריונים עובר/נכשל, (ה) איך מסיימים.

## א · מה מוכן ומה בונים

**מוכן, בריפו של הפרוטוטיפ (main):**
- **`widgets/json-table.js`** — ספריית הרינדור. קובץ אחד, בלי תלויות, מזריק את ה-CSS שלו.
  `hkJsonTable.render(containerElement, json, {title})` מחזיר `{reload(json), destroy()}`. זה הקוד
  שמפרסר את הנתונים ומצייר: טיפוסים, פורמט מספרים ותאריכים, צ׳יפים, מיון, חיפוש, סה״כ, CSV, ובלוק `view`.
  **לקחת כמו שהוא.** לא לכתוב פרסר משלך.
- **`widgets/widget-json-table.html`** — המעטפת בפרוטוטיפ (מאיפה מגיע ה-JSON + דיווח גובה). לעיון, לא לקחת.
- **`docs/WIDGET_JSON_CONTRACT.md`** — החוזה: פורמט הקובץ (types/rows/received_at) ובלוק `view`
  שבו השרת אומר איך להציג. הספרייה מממשת אותו במלואו.
- **`extrnal_widget/*.json` + `*.view.json`** — חמישה קבצים אמיתיים מהשרת עם ה-`view` שלהם, לבדיקה.

**בונים:** ווידג׳ט אחד במערכת הווידג׳טים הקיימת, **חצי מסך** (כמו כל ווידג׳ט), שמקבל
`company` + `widget`, מביא את ה-JSON מהשרת ומרנדר אותו עם הספרייה. ווידג׳ט אחד לכל הטבלאות —
אין קוד ייעודי לטבלה מסוימת. חמש טבלאות = חמישה מופעים של אותו ווידג׳ט עם פרמטרים שונים.

## ב · מאיפה הנתונים

`GET /api/widgets/{company}/{widget}` בשרת הווידג׳טים (אפיון השרת: `אפיון-שרת-הווידגטים.md`).
JWT של המערכת ב-`Authorization: Bearer`, אותו middleware של `/api/*`. התשובה היא הקובץ כפי שנשמר
+ `received_at`. אם השרת מחזיר `view` — הוא בפנים; אם לא — הספרייה מציגה ברירות מחדל.
לרשימת הטבלאות של חברה: `GET /api/widgets/{company}` (בשביל בורר "איזו טבלה" בהוספת ווידג׳ט).

הפרמטרים של מופע הווידג׳ט (נשמרים בלוח כמו כל ווידג׳ט): `company`, `widget`, ו-`title` (רשות —
הכותרת אם ה-JSON לא מביא `view.title`).

## ג · איך מפרסרים ומרנדרים — בקצרה, הכל ב-json-table.js

```js
// בתוך הווידג׳ט שלך, אחרי שהבאת את ה-JSON:
var api = hkJsonTable.render(containerEl, json, { title: params.title, onRender: reportHeight });
// רענון (טיימר / כפתור): api.reload(newJson)   · הסרה: api.destroy()
```

מה הספרייה עושה עם הקלט (למי שצריך להבין, לא לשכתב):
1. `rows` = מערך אובייקטים; מפתחות השורה הראשונה = העמודות, בסדר הזה. `types[עמודה]` = טיפוס
   (`text` ברירת מחדל). טיפוס לא מוכר → שגיאה מוצגת בתוך הווידג׳ט, לא קריסה.
2. `view` (רשות): כותרת, מטבע, מיון התחלתי, סדר עמודות, הסתרה, יחידות, עשרוניות, צבעים לפי סימן/סף,
   פסים, צ׳יפים, קישורים, מה בשורת הסה״כ, צביעת שורה. **צבעים בשמות בלבד** (red/amber/green/blue/gray/navy).
3. תצוגה: מיון בלחיצה על כותרת · חיפוש על text/status · סה״כ (סכום/ממוצע/…) על המסונן, דביק לתחתית ·
   "מוצגות N מתוך M" · "עודכן dd.mm.yyyy HH:mm" · CSV של המסונן עם BOM · ערך חסר `—` ·
   `money` = `₪1,234`, שלילי באדום · מספרים `tabular-nums` ו-LTR · גלילה פנימית מעל 440px.
4. **חצי מסך:** הריווח מכוון לזה. טבלה עם יותר מ-4–5 עמודות — השרת מסתיר עמודות ב-`view`
   (`hidden`). הווידג׳ט לא מחליט לבד מה להסתיר ולא משנה רוחב.

CSS: הספרייה מזריקה `<style id="hk-json-table-css">`. אם מערכת הווידג׳טים שלכם מעדיפה קובץ CSS —
`hkJsonTable.css` הוא המחרוזת, אפשר להוציא לקובץ. הגופן Rubik (או של העמוד).

## ד · קריטריונים — עובר / נכשל

1. ווידג׳ט אחד, פרמטרים `company`/`widget`/`title`; חמשת הקבצים ב-`extrnal_widget/` מוצגים דרך
   אותו ווידג׳ט **בלי שינוי קוד** בין קובץ לקובץ.
2. הרינדור זהה לפרוטוטיפ: פותחים `widgets/widget-json-table.html?file=gviya__payment_terms` ליד
   הווידג׳ט שלכם עם אותו JSON — אותן עמודות, אותם צבעים, אותו סה״כ.
3. חצי מסך. אין גלישה אופקית ב-4 עמודות; ב-5+ עמודות שה-`view` לא הסתיר — גלילה אופקית פנימית,
   לא שבירת הכרטיס.
4. שינוי חשבון/פרמטר → `api.reload`, בלי ליצור ווידג׳ט חדש. גובה הכרטיס מתעדכן (`onRender`).
5. שגיאת שרת (401/404/500) או JSON לא תקין → הודעה בעברית בתוך הכרטיס, הלוח ממשיך לעבוד.
6. `view` עם שדה לא מוכר או צבע לא מוכר → מתעלמים, לא שגיאה.
7. CSV נפתח באקסל עם עברית תקינה, ומכיל רק מה שמוצג (אחרי חיפוש, לפי סדר העמודות המוצג).
8. אין `<select>` נייטיב, אין `alert`, אין "HK" בטקסט שבעל העסק רואה.

## ה · איך מסיימים

פותחים את הפרוטוטיפ (`widgets/widget-json-table.html?file=…` לכל אחד מחמשת הקבצים) ואת הווידג׳ט
שבניתם זה לצד זה, ועוברים על 1–8. לא Done — תגובה "מוכן לבדיקה" במשימה, אנחנו בודקים בסטייג׳ינג.
