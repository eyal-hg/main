# לוח המשימות — `board/` (04.09.2026)

**`board/index.html`** — מערכת המשימות שלנו (במקום Asana). דף אחד, בגיט, נפרס עם המוקאפ לנטליפיי.
- **מרכז**: כל הפריטים הפתוחים, לפי אדם ולפי מסך, והוספה מהירה (גם "כללי" — פריט שלא שייך למסך).
- **לכל אדם** (אייל · אופיר · עומרי · עידו): מה עליו, מקובץ לפי מסך, עם MD ⤓ להורדה ל-AI.
- **לכל מסך**: ארבעה טאבים — **אפיון · נשאר לפתח · תיקונים · בדיקות**. כל פריט: כותרת, על מי, חומרה,
  "היום בסטייג׳ינג" / "צריך להיות", צילומים. פס ירוק = המסך סגור.
- **זרימה**: "אופיין" → עובר ל"נשאר לפתח"; "נבנה"/"תוקן" → עובר ל"בדיקות" (על אייל); "נבדק" → סגור.
- **עריכה**: כפתור "עריכה" פותח את כל הטקסטים, השיוך והחומרה; "שמירה" כותבת קומיט לגיט דרך
  `netlify/functions/save-board.mjs` (סיסמת הלוח + GITHUB_TOKEN ב-Netlify). מקומית (file://) — מוריד `data.js`
  להחלפה. טיוטה נשמרת בדפדפן עד השמירה.
- **נתונים**: `board/data.js` (`window.HK_BOARD`). תמונות: `board/img/`.
- **מהמוקאפ**: שני אייקונים ליד ה-"?" (`js/docs-links.js`) פותחים את הלוח על המסך הנוכחי.
- `TASK.md` בתיקיות `docs/tasks/<תאריך>-<מסך>/` נשאר האפיון המלא; הלוח הוא "מה נשאר עכשיו".
