0 · לפני הכל — מפת המסכים

  • SCREENS.md בשורש הריפו הוא המקור היחיד: טאב → קובץ. מסך שלא מופיע שם אינו חלק מהמערכת.
  • כל הגרסאות הישנות עברו ל-legacy/ (עם README מה החליף מה). לא לעבוד מ-legacy. למשל past-cashflow.html הישן — לא המסך; המסך הוא docs/cli/cashflow-past.html.

1 · העוזר על הדוח — מה נשלח לסוכן

  • העוזר עונה רק על הדוח שהמסך מציג עכשיו: אותם חודשים, אותו חשבון, אותן שורות. הפקה מחדש / החלפת חשבון → העוזר עונה על הדוח החדש.
  • בכל שאלה נשלח מטען שנבנה מהדוח המוצג: חודשים, חשבון, יתרות פתיחה/סגירה, הפרש חודשי, כל הקבוצות → קטגוריות → גורמים (כולל דריל שסגור על המסך), הרצועות המחושבות (רווח גולמי, הפרש תפעולי, הפרש חודשי), אחוז עלות המכר מהמחזור, ושלוש התובנות. מבנה JSON מלא באפיון §1.1. בפרוטוטיפ: reportContext().
  • לא נשלח: תנועות בודדות, נתונים מחוץ לטווח, חברות אחרות.
  • המסך: פס הקשר מתחת לראש הפאנל "עונה על הדוח שמוצג · אפריל–יולי 2026 · כל החשבונות"; אחרי הפקה/החלפת חשבון — הערה בתוך השיחה שהעוזר עונה מעכשיו על הדוח החדש.
  • כללי התשובה (system prompt): רק מהמטען; כל מספר מהדוח או חישוב ישיר ממנו עם ציון חודש/קטגוריה; קצר, בשפת הלקוח, white-label; שאלה מחוץ לדוח → לומר זאת ולהפנות (תזרים עתידי / עוזר AI).
  • API (סקיצה): POST /companies/:id/cashflow-picture/ask {report, question, thread_id?} → {answer_html, used[]}.

2 · תיקוני העיצוב

  • הפס הכהה — שורה אחת קבועה: "תמונת תזרים" + הפרש מצטבר · פתיחה · סגירה מימין, ייצוא · שליחה משמאל. לא נשבר לשתי שורות (היה נשבר ב-1512px).
  • הבקרות ירדו לשורה בהירה מתחת לפס: "טווח הדוח · מתעדכן בהפקה" (מ־ / עד / הפקה) ו"חשבונות · מתעדכן מיד".
  • ערך חסר בתא: — במקום ---.
  • הכפתור נקרא "שליחה" (לא "שליחה ללקוח") ומוצג לכולם — היועץ שולח ללקוח, בעל העסק שולח לעצמו.
  • לא השתנה: אדום עמוק רק על הפרש שלילי / יתרה שלילית / אחוז עלות המכר; הוצאה רגילה בלי צבע; שורת השאלה על משטח קורל.

3 · קריטריוני קבלה

  1. החלפת חשבון → פס ההקשר מציג את החשבון החדש, ושאלה על ההפרש מחזירה את המספר של הדוח החדש.
  2. הפקת טווח אחר → אותו דבר לחודשים, והערה "הדוח הופק מחדש" בשיחה.
  3. שאלה מחוץ לדוח → "אין בדוח הזה" עם הפניה, לא ניחוש.
  4. כל מספר בתשובה ניתן לאיתור בדוח המוצג.
  5. ב-1280–1680px הפס הכהה שורה אחת.
  6. legacy/past-cashflow.html לא נטען משום מקום.
