## ג · מה המסך עושה, למי, ומאיפה הנתונים

**התפקיד של המסך:** מה קורה **היום** — הציר של היום (פגישות, שיחות, משימות עם שעה), המשימות של היום
בצד, ומה שדורש תשומת לב מהזיכרון. שום דבר כאן לא נערך "בגדול" — זה מסך של סריקה ופעולה מהירה.

### ג.1 מי רואה מה

כל התפקידים בממשק היועץ ובממשק מנהל התזרים. הנתונים: **הפגישות/השיחות של המשתמש** (הוא המזמן או
היועץ/מנהל של החברה), **המשימות של המשתמש** (מסך "משימות"), **הזיכרון של החברות שהוא רואה**.

### ג.2 מקורות (לא להמציא)

| אזור | מקור |
|---|---|
| **הציר של היום** | איחוד של: (א) הפגישות והשיחות של היום מהיומן (`calendar` / מסך התקשורת) — עם שם החברה, שם הפגישה, משתתפים, משך, ערוץ (Zoom/טלפון); (ב) **משימות של היום שיש להן שעה** (`advisor_task.due_time`). ממוין לפי שעה |
| סוג שורה (פס בקצה הפנימי) | **פגישה** = ירוק · **שיחה** = קורל · **משימה** = סגול. הסוג מגיע מהמקור (סוג האירוע ביומן / משימה) |
| "הסתיימה" (ירוק) · "הוקלטה 46 דק׳" | הפגישה עברה ויש הקלטה — מהמערכת הקיימת של ההקלטה והתמלול |
| "ההכנה נפתחה" (ירוק) / "ההכנה לא נפתחה" (ענבר) | האם ההכנה לפגישה (מסך "הכנה לפגישה" בכרטיס החברה) נפתחה על ידי המשתמש לפגישה הזאת. אין מנגנון כזה → לא להציג את הטקסט |
| "מה נולד מהפגישה [N]" | לפגישה שהסתיימה **והוקלטה**: מצב הסיכום (מוכן לאישור / אושר) · עדכוני הזיכרון שנולדו ממנה (קטגוריה · טקסט · שעה) · N = מספר עדכוני הזיכרון + 1 אם יש סיכום לאישור. אין הקלטה → אין צ׳יפ |
| **"האירוע הבא"** (בפס) | האירוע הבא על הציר אחרי "עכשיו" מסוג פגישה/שיחה. "בעוד h:mm" נספר לאחור חי. אין → "אין אירועים נוספים היום" בלי כפתורים |
| "הקלטה" | מתחיל הקלטה לפגישה הבאה — **אותו מנגנון ההקלטה הקיים במערכת** (מסך ההקלטה / הלינק `?openmeeting=`). כפתור לא מוצג לאירוע שאין לו אפשרות הקלטה |
| "הכנה לפגישה" | פותח את מסך ההכנה לפגישה של החברה, לפגישה הזאת |
| **המשימות שלי** (צד) | `advisor_task` של המשתמש: **באיחור** (למעלה) + **היום**, פתוחות ובוצעו־היום. "N להיום" = פתוחות להיום. הסדר ידני (`sort_order`) — גרירה |
| "שלי" / "מפגישה" | `source` של המשימה |
| **תשומת לב** | עדכוני הזיכרון האחרונים מכל החברות של המשתמש (3 הימים האחרונים, עד 8): הטקסט · חברה · מי אמר · המקור (פגישה / קבוצה / יומן / שיחה / הודעה) · מתי. **נקודה אדומה** כשהעדכון מסומן שלילי (קטגוריות: ירידה בשביעות רצון, ביטול פגישה, תלונה) — לפי הסימון של מנוע הזיכרון; אין סימון כזה → כל הנקודות תכלת |

### ג.3 חוזה URL

`?prep=<company_id>` — מדגיש את הפגישה של החברה ופותח את ההכנה · `?c=<company_id>` — מדגיש את הפגישה
של החברה · `?q=` — מדגיש את השורה הראשונה שמכילה את הטקסט. הדגשה = מסגרת תכלת 1.6 שניות.
