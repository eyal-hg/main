# חוזה JSON בין שרת הווידג׳טים לווידג׳ט "טבלה מ-JSON" — גרסה 1.1

מסמך לצד השרת (ול-AI שלו). הווידג׳ט: `widgets/widget-json-table.html` בריפו של הדשבורד.
**גרסה 1.0** היא הפורמט הבסיסי של שרת הווידג׳טים (`types` + `rows`), והיא ממשיכה לעבוד כמו שהיא.
**גרסה 1.1** מוסיפה בלוק אחד אופציונלי, `view`, שאומר לווידג׳ט איך להציג. כל שדה ב-`view` הוא רשות;
מה שלא נשלח מקבל ברירת מחדל סבירה.

**העיקרון:** השרת יודע מה המספרים אומרים, הווידג׳ט יודע לצייר. השרת אומר "העמודה הזאת היא ימים,
אדום מתחת ל-50, מיין לפי חויב"; הווידג׳ט לא מקבל hex ולא CSS. הצבעים הם **שמות מתוך פלטה סגורה**.

## 1 · הבסיס (1.0, ללא שינוי)

```json
{
  "types": { "לקוח": "text", "חויב": "money", "ימים בפועל": "number", "תאריך": "date", "גבייה": "percent", "סטטוס": "status" },
  "rows":  [ { "לקוח": "אופטיקנה", "חויב": 424891, "ימים בפועל": 14, "תאריך": "2026-09-03", "גבייה": 93.6, "סטטוס": "פתוח" } ],
  "received_at": "2026-09-03T09:00:12+03:00"
}
```

- מפתחות השורה = כותרות העמודות, בעברית. סדר העמודות = סדר המפתחות בשורה הראשונה.
- שישה טיפוסים: `text` · `number` · `money` · `date` (`YYYY-MM-DD`) · `percent` (0–100) · `status`. עמודה בלי טיפוס = `text`.
- ערך חסר = `null` או מפתח חסר → מוצג `—`.
- ברירות המחדל בלי `view`: כותרת = שם הווידג׳ט · חיפוש על `text`/`status` · CSV · שורת סה״כ (סכום ל-`money`/`number`, ממוצע ל-`percent`) · `money` = `₪1,234`, שלילי באדום · `status` לפי מפת הצבעים הקבועה · בלי מיון התחלתי.

## 2 · בלוק `view` (1.1) — הכל רשות

```json
"view": {
  "title": "תנאי תשלום",
  "subtitle": "לפי לקוח · 12 חודשים",
  "currency": "₪",
  "sort": { "by": "חויב", "dir": "desc" },
  "search": true, "csv": true, "total": true,
  "freeze_first": true,
  "column_order": ["לקוח", "חויב", "שולם", "פתוח"],
  "columns": {
    "גבייה":      { "decimals": 1, "bar": { "max": 100, "color": "green" },
                    "rules": [ { "lt": 50, "color": "red" }, { "lt": 90, "color": "amber" }, { "gte": 90, "color": "green" } ] },
    "ימים בפועל": { "unit": "ימים", "color": { "pos": "gray" } },
    "פער":        { "color": { "neg": "green", "pos": "red", "zero": "gray" }, "footer": "avg" },
    "מספר חשבונית": { "hidden": true },
    "לקוח":       { "link": "https://crm.example.co.il/customers/{מספר לקוח}" },
    "סוג":        { "chip": true, "colors": { "תעודת חיוב": "amber", "חשבונית מס": "blue" } }
  },
  "footer": { "חויב": "sum", "שולם": "sum", "גבייה": "avg", "לקוח": "count" },
  "row_color": { "col": "סטטוס", "map": { "באיחור": "red", "שולם": "green" } }
}
```

### 2.1 שדות ברמת הטבלה

| שדה | ערך | ברירת מחדל | מה זה עושה |
|---|---|---|---|
| `title` | מחרוזת | שם הווידג׳ט | כותרת הכרטיס |
| `subtitle` | מחרוזת | — | שורת משנה ליד הכותרת |
| `currency` | `"₪"` · `"$"` · `"€"` · כל מחרוזת קצרה | `"₪"` | הסימן לעמודות `money` (אפשר לדרוס פר עמודה) |
| `sort` | `{by, dir}` · `dir` = `asc`/`desc` | בלי מיון | המיון ההתחלתי; המשתמש עדיין יכול ללחוץ על כותרת |
| `search` | boolean | `true` | תיבת החיפוש |
| `csv` | boolean | `true` | כפתור הורדת CSV |
| `total` | boolean | `true` | שורת הסה״כ |
| `freeze_first` | boolean | `false` | העמודה הראשונה נשארת קבועה בגלילה אופקית (טבלאות רחבות) |
| `column_order` | מערך שמות | סדר המפתחות | סדר תצוגה; עמודה שלא ברשימה נדחפת לסוף |
| `footer` | `{עמודה: mode}` | לפי טיפוס | מה מופיע בשורת הסה״כ לעמודה: `sum` · `avg` · `min` · `max` · `count` · `none` |
| `row_color` | `{col, map:{ערך: צבע}}` | — | צביעת רקע עדינה של שורה שלמה לפי ערך בעמודה (למשל "באיחור" → אדום) |

### 2.2 שדות פר עמודה — `columns.<שם העמודה>`

| שדה | ערך | מה זה עושה |
|---|---|---|
| `label` | מחרוזת | כותרת אחרת מהמפתח (המפתח נשאר לחיפוש ול-CSV) |
| `type` | אחד משישה הטיפוסים | דורס את `types` |
| `hidden` | boolean | העמודה לא מוצגת (כן יוצאת ל-CSV? לא — CSV הוא מה שמוצג) |
| `decimals` | 0–4 | ספרות אחרי הנקודה ל-`money` / `number` / `percent` (ברירת מחדל: 0, ואחוז עם שבר → 1) |
| `unit` | מחרוזת קצרה | סיומת קטנה ואפורה אחרי המספר: "ימים", "יח׳", "ק״ג" |
| `currency` | מחרוזת | סימן מטבע לעמודה הזאת בלבד |
| `align` | `start` · `center` · `end` | יישור בתא (ברירת מחדל: מספרים לסוף, טקסט להתחלה) |
| `color` | `{neg, pos, zero}` | צבע הערך לפי הסימן. למשל פער: שלילי ירוק, חיובי אדום |
| `rules` | `[{lt\|lte\|gt\|gte\|eq: מספר, color}]` | סף מספרי → צבע. הראשון שמתקיים מנצח. גובר על `color` |
| `bar` | `{max, color}` | פס דק מתחת למספר, באורך `value/max`. למשל אחוז גבייה מתוך 100 |
| `chip` | boolean | עמודת טקסט מוצגת כצ׳יפ (כמו `status`) |
| `colors` | `{ערך: צבע}` | צבעי צ׳יפ לעמודת `status`/`chip`, דורס את המפה הקבועה |
| `link` | תבנית עם `{שם עמודה}` | הערך הופך לקישור; `{…}` מוחלף מערכי אותה שורה |
| `footer` | `sum` · `avg` · `min` · `max` · `count` · `none` | כמו `footer` ברמת הטבלה, לעמודה זו |

### 2.3 הפלטה — שמות בלבד

| שם | משמעות במוצר | איפה להשתמש |
|---|---|---|
| `red` | **סכנה כספית** | חוב באיחור, חריגה, שלילי שמזיק. לא לכל מינוס |
| `amber` | דורש תשומת לב | בין הסף לטוב, "בטיפול" |
| `green` | תקין / הושג | שולם, מעל היעד |
| `blue` | מצב ניטרלי פעיל | פתוח, בביצוע |
| `gray` | לא רלוונטי / מידע | טיוטה, מבוטל, ערכי עזר |
| `navy` | הדגשה מבנית | ערך מרכזי שרוצים שיבלוט, בלי שיפוט |

מפת ה-`status` הקבועה נשארת כברירת מחדל: סגור/שולם/הושלמה = green · פתוח/מחכה לתשלום/בביצוע = blue ·
באיחור/באיחור לא שולם = red · טיוטה/מבוטל/לא נשלחה = gray · אחר = gray.

## 3 · דוגמאות מלאות לשלושת הווידג׳טים הראשונים

**תנאי תשלום** — הפער (נומינלי מול בפועל) הוא המספר החשוב:
```json
"view": { "title": "תנאי תשלום", "sort": { "by": "פתוח", "dir": "desc" }, "freeze_first": true,
  "columns": { "נומינלי": { "unit": "ימים" }, "בפועל": { "unit": "ימים" },
               "פער": { "unit": "ימים", "color": { "neg": "green", "pos": "red", "zero": "gray" }, "footer": "avg" } } }
```

**יתרות לקוחות** — "מתוכה באיחור" מסוכן רק כשהוא גדול מאפס:
```json
"view": { "title": "יתרות לקוחות", "sort": { "by": "מתוכה באיחור", "dir": "desc" },
  "columns": { "מתוכה באיחור": { "rules": [ { "gt": 0, "color": "red" } ], "bar": { "max": 50000, "color": "red" } },
               "מסמכים": { "footer": "sum" } } }
```

**טרם חויב** — הגיל בימים מדורג:
```json
"view": { "title": "טרם חויב", "sort": { "by": "גיל בימים", "dir": "desc" },
  "columns": { "גיל בימים": { "unit": "ימים", "rules": [ { "gte": 90, "color": "red" }, { "gte": 30, "color": "amber" } ] },
               "סוג": { "colors": { "תעודת חיוב": "amber", "תעודת משלוח": "blue" } } },
  "row_color": { "col": "סוג", "map": {} } }
```

## 4 · כללים

1. **שדה לא מוכר ב-`view` — מתעלמים ממנו**, לא שגיאה. השרת יכול להקדים את הווידג׳ט.
2. **צבע שלא בפלטה → `gray`.** אין hex, אין CSS.
3. **`view` לא משנה נתונים.** CSV מכיל את הערכים הגולמיים של מה שמוצג (אחרי חיפוש, לפי סדר העמודות המוצג).
4. **`types` נשאר חובה** לכל עמודה שאינה טקסט. `view.columns[].type` הוא דריסה לחריגים, לא תחליף.
5. השרת מאמת רק את 1.0 (כמו היום). את `view` הוא מעביר כמו שהוא, בלי לבדוק — הווידג׳ט סלחן.

הכל בסעיף 2 ממומש ב-`widgets/widget-json-table.html`. הדוגמה המובנית בווידג׳ט (בלי `?file=`) מדגימה:

## 6 · הטמעה בדף זר (למי שמרנדר מחוץ לדשבורד)

- **`widgets/json-table.js`** הוא הקובץ הקנוני. כל ה-CSS שלו מסוקף מתחת ל-`.hkjt` (כולל טוקני הצבע) —
  הוא **לא דולף החוצה** לדף המארח.
- נגד דליפה **פנימה** (CSS של הדף המארח שתופס `td`, `.sub`, `.bar` וכד׳): `hkJsonTable.render(el, json, {shadow:true})`
  מרנדר בתוך Shadow DOM — בידוד מלא, בלי iframe. iframe עם `srcdoc` עובד גם, אבל דורש דיווח גובה.
- **רוחב היעד:** ווידג׳ט בדשבורד הוא חצי מסך — כ-**600px** במסך 1512 וכ-700px ב-1680. צילומי הדוגמה
  ב-`server-examples/*.png` נעשו ב-760px. תצוגה מקדימה: לתחום ל-620px, לא למתוח ל-1200.
